Registering the Webhook with Meta

1

Find your webhook URL

Open the app → Settings tab. The URL is shown under Webhook URL. It looks like: https://your-site.netlify.app/api/webhook

2

Register in Meta Business Manager

Go to business.facebook.com → WhatsApp Manager → Configuration. Paste the URL and your WEBHOOK_VERIFY_TOKEN.

3

Subscribe to webhook fields

Enable: messages, message_template_status_update. The first delivers incoming messages; the second delivers template approval notifications.

Chapter 5

Assets Library

Upload images, videos, and documents to cloud storage. Get permanent public URLs for use in template headers and broadcast campaigns.

What is the Assets Library?

The Assets Library is a media store built on Supabase Storage. Every file you upload gets a permanent, publicly accessible HTTPS URL — exactly what WhatsApp requires for template headers and broadcast media attachments.

Files are organised per business, so Garment Retail and LawAid AI each have their own separate asset folders.

When do you need this? Any time you create a template with an Image, Video, or Document header, or send a broadcast with a media attachment — you need a public URL. Upload it here first.

Supported File Types

TypeFormatsRecommended sizeMax
🖼️ ImageJPEG, PNG, GIF, WebP800 × 418 px (1.91:1 ratio)10 MB
🎬 VideoMP4Under 16 MB for best delivery10 MB
📄 DocumentPDFAny size10 MB

Uploading a File

1

Open the Templates tab

Click 📋 Templates in the top navigation. The Assets Library card is at the top of the page.

2

Select your business

Use the Business dropdown in the Assets Library card. This determines which business folder the file is stored under.

3

Upload the file

Drag and drop the file onto the upload zone, or click to browse. Multiple files can be uploaded at once. A progress indicator shows each file uploading.

4

Copy the public URL

The file appears in the gallery below the upload zone. Click 📋 Copy URL on the asset card. The URL is now in your clipboard — ready to paste into a template header or broadcast.

Deleting an Asset

Click the 🗑 button on any asset card. You will be asked to confirm. Deletion is permanent — any template or broadcast that referenced the URL will no longer display the image.

Before deleting — check that no live approved template or active broadcast references this asset URL. WhatsApp will show a broken media placeholder to customers.

Using an Asset in a Template

In the Create New Template form, set Header Type to 🖼️ Image (or Video/Document). A URL field and 📁 Browse Assets button appear. Click Browse Assets to open a picker showing your uploaded files — click ✔ Use to auto-fill the URL.

Using an Asset in a Broadcast

In the Broadcasts tab, select 🖼️ Image or 🎬 Video as the message type. Paste the asset URL from your clipboard into the Media URL field.

Image best practices for WhatsApp: Use 800 × 418 px JPEG at 72 dpi. Keep file size under 500 KB for fastest delivery. Avoid text-heavy images — WhatsApp compresses them aggressively.
Chapter 6

Template Management

Create, submit, and manage WhatsApp message templates. Templates are required for reaching customers outside the 24-hour messaging window.

Overview

WhatsApp message templates are pre-approved message formats that allow you to contact customers outside the 24-hour messaging window — essential for broadcast campaigns, appointment reminders, and order updates.

All templates must be reviewed and approved by Meta before use. This dashboard lets you create, manage, and monitor that entire process without leaving the app.

Message TypeWhen it worksNeeds Meta Approval?
Free-form textWithin 24 hrs of customer's last messageNo
TemplateAny time — even after 24 hrsYes

Creating a Template

Open the 📋 Templates tab and fill in the Create New Template form.

1

Business *

Choose which WhatsApp number this template belongs to.

2

Template Name *

Lowercase letters, numbers, and underscores only. Permanent after submission.

Examples: summer_sale_2026 · appointment_reminder · order_shipped

3

Category *

  • 📣 Marketing — promotions, offers, newsletters
  • 🔧 Utility — order updates, reminders, account alerts (lower cost)
  • 🔐 Authentication — OTPs and verification codes
4

Language *

English (US/GB), Hindi, or Marathi. Submit separate templates for each language you need.

5

Header (optional)

  • None — text body only
  • 📝 Text — bold title, max 60 chars. Use {{1}} for one variable.
  • 🖼️ Image / 🎬 Video / 📄 Document — paste URL from Assets Library or click Browse Assets. The file is sent at broadcast time.
6

Body *

Main message text, max 1024 chars. Personalise with {{1}}, {{2}}, etc.

Example: Hi {{1}}, your order {{2}} has been dispatched and will arrive by {{3}}.

When you use variables, Example value inputs appear automatically. Fill them in — Meta uses these to review your template.

7

Footer (optional)

Short grey text below body, max 60 chars. No variables. Commonly used for opt-out notice: "Reply STOP to unsubscribe".

8

Buttons (optional)

Up to 3 buttons. Types:

  • 💬 Quick Reply — customer taps to send a preset reply
  • 🔗 URL — opens a link. Append {{1}} at the end for a dynamic suffix
  • 📞 Phone — dials a number. Format: +919876543210
Do not mix Quick Reply and CTA (URL/Phone) buttons in the same template.
9

Submit

Click 📤 Submit for Meta Approval. The template status will be PENDING. Meta typically reviews within minutes to a few hours.

Approval & Notifications

Approval statuses

StatusMeaning
PENDINGSubmitted and awaiting Meta review. Usually resolves in minutes to a few hours.
APPROVEDReady to use in Broadcasts.
REJECTEDNot approved. Rejection reason is shown in the notification banner and template list.
PAUSEDPaused by Meta due to low engagement or quality issues. Cannot be sent until re-enabled.

How notifications work

When Meta approves or rejects a template, it sends a webhook event to /api/webhook. The app captures this and displays a notification banner at the top of the Templates tab the next time you open it.

  • ✅ Green banner — APPROVED, template is ready to use
  • ❌ Red banner — REJECTED, reason is shown in the banner

Dismiss each banner by clicking ✕.

Prerequisite for notifications: Subscribe to the message_template_status_update webhook field in Meta Business Manager → WhatsApp Manager → Configuration → Webhook fields.

If your template is rejected

  • Read the rejection reason in the notification banner or template list card
  • Common reasons: promotional language in a Utility template, vague body text, missing opt-out in Marketing templates, sequential variable numbers skipped
  • Delete the rejected template, fix the issue, and resubmit (you can reuse the same name)

Viewing & Deleting Templates

The Your Templates card at the bottom of the Templates tab shows all templates for the selected business, live from Meta's API.

  • Use the status filter to show only Approved, Pending, or Rejected templates
  • Each card shows the template name, status, category, language, header, body preview, footer, and buttons
  • Click 🗑 Delete to remove a template. Deletion is permanent — approved templates that have been sent will stop working immediately

Using Approved Templates in Broadcasts

1

Go to 📢 Broadcasts

Click the Broadcasts tab in the top navigation.

2

Select Message Type → Template

Click the 📋 Template card in the Message Type row.

3

Enter the exact template name

Type the name exactly as submitted (e.g. summer_sale_2026). Case-sensitive.

4

Fill in variables and media

Add body variable values. Use personalisation tokens:

  • {name} → contact's full name
  • {first_name} → first word of name
  • {phone} → contact's phone number

If your template has an image/video header, paste the URL from Assets Library into the Media URL field.

5

Select recipients and send

Choose all opted-in contacts or filter by tag, then click 📤 Send Campaign.

Tips & Best Practices

  • Utility vs Marketing: Use Utility for transactional messages (order updates, reminders). It's cheaper per message and approves faster.
  • Opt-out for Marketing: Always add a footer like "Reply STOP to unsubscribe" or a Quick Reply button. Meta requires it.
  • Specific body text: Vague messages like "Check this out!" are often rejected. Be clear about what you're communicating.
  • Realistic example values: When your body has {{1}}, fill in a realistic example like "Priya Sharma" not "Example1" — better examples lead to faster approvals.
  • Sequential variables: Always use {{1}}, {{2}}, {{3}} in order. Do not skip numbers.
  • Image headers: Visuals significantly increase engagement. Use 800 × 418 px JPEG from the Assets Library.
