🔑 Environment Variables

Set these in your Netlify dashboard → Site Settings → Environment variables:

Variable Description
SUPABASE_URLYour Supabase project URL
SUPABASE_SERVICE_KEYSupabase service role secret key
ANTHROPIC_API_KEYYour Anthropic Claude API key
WEBHOOK_VERIFY_TOKENCustom string you create (used in Meta webhook config)

📡 Webhook Setup Checklist

✅ Deploy this app to Netlify
✅ Set all environment variables in Netlify
✅ Go to developers.facebook.com → Your App → WhatsApp → Configuration
✅ Set Callback URL: https://YOUR-SITE.netlify.app/api/webhook
✅ Set Verify Token: same value as WEBHOOK_VERIFY_TOKEN
✅ Subscribe to: messages
✅ Run the Supabase schema SQL to create tables
✅ Update the businesses table with your real Phone Number IDs and access tokens
